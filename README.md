# PDFSigner

一个纯前端的 PDF 电子签章工具，在浏览器中即可完成 PDF 的盖章、骑缝章加盖与导出，无需服务端、无需安装，打开即用。

## 功能特性

- **PDF 预览**：本地加载 PDF 文件并按页渲染预览，支持最多 50MB 的文件。
- **签章加盖**：选择图片作为签章，拖动到页面任意位置，支持：
  - 放大 / 缩小
  - 旋转
  - 调整透明度
  - 复制
  - 删除
- **骑缝章**：将签章按页数垂直切片，自动贴到每一页的右侧边，拼合出跨页连续的骑缝章效果。
  - **支持多组并存**：甲乙双方可各自生成一组骑缝章，同页内多组自动垂直错开排布，避免互相覆盖。
  - **尺寸联动**：调整参考章的缩放后，对应的骑缝章会同步更新为一致大小。
- **导出 PDF**：一键导出带签章的 PDF，保持原始清晰度，页数与源文件一致，无多余空白页。
- **不持久化**：签章位置、参数不自动保存，刷新或重新载入页面后签章不会恢复，需重新操作。

## 目录结构

```
PDFSigner/
├── index.html          # 主页面，包含控制面板、预览区与全部逻辑
├── css/
│   └── bulma.css       # Bulma 样式框架
└── js/
    ├── jquery.js       # jQuery
    ├── jq_ui.js        # jQuery UI（拖拽功能）
    ├── FileSaver.js    # 文件保存
    ├── pdf.js          # PDF.js（PDF 解析渲染）
    ├── pdf.worker.js   # PDF.js Worker
    └── html2pdf.js     # html2pdf（导出 PDF）
```

## 使用方法

1. **选择 PDF 文件**：点击「选择文件...」载入需要签章的 PDF，页面会按页渲染预览。
2. **选择签章图片**：载入 PDF 后，点击「选择图片...」选择公章图片，会作为可拖动的签章添加到预览区。
3. **调整签章**：点击签章选中后，使用「放大 / 缩小 / 旋转 / 透明 / 复制 / 删除」按钮调整，也可直接拖动改变位置。
4. **加盖骑缝章**：选中参考章后，点击「骑缝章」按钮，自动为每一页生成右侧骑缝章切片。可重复对不同章点击以生成多组骑缝章。
5. **导出 PDF**：在「重命名」中设置输出文件名，点击「导出 PDF」保存结果。
6. **重置**：点击「重置」重新加载页面，回到初始状态。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 放大 / 缩小 | 以 0.1 为步进调整签章缩放，骑缝章同步更新 |
| 旋转 | 每次顺时针旋转 15° |
| 透明 | 每次降低 15% 透明度，到最低后恢复 |
| 复制 | 在原章基础上偏移复制一份 |
| 删除 | 删除选中的签章（普通章会连带清除其骑缝章组） |
| 骑缝章 | 以当前选中的章为参考，生成一组跨页骑缝章 |

## 技术栈

- jQuery / jQuery UI：DOM 操作与拖拽交互
- PDF.js：PDF 解析与页面渲染
- html2pdf：将预览区（含签章）转换为 PDF 并导出
- FileSaver：触发浏览器下载

## 说明

- 所有处理均在浏览器本地完成，PDF 文件和签章图片不会上传到任何服务器，保障数据隐私。
- 骑缝章由参考章图片在浏览器端垂直切片生成，切片宽度 = 图片宽度 ÷ 页数，按页高度等比缩放后贴于右侧。
